# How-to guides

Task-oriented recipes for real work. Pick the task you're trying to do; for
the underlying ideas see the [explanation](../explanation/), for the full set
of options and config keys see the [reference](../reference/).

- [**Config**](config.md) — create your config with `ap init` or by hand.
- [**Mounts & context**](mounts.md) — give the agent files, folders, and
  context to work with.
- [**Pi settings**](settings.md) — bake pi settings (incl. its `packages`)
  into the sandbox image.
- [**Git work**](git.md) — keep the agent on its own private branch with
  ephemeral git sessions.
- [**Skills**](skills.md) — give an agent skills it can use, no rebuild.
- [**Profiles to taste**](recipes.md) — example profile shapes to copy.
- [**Contribute**](contribute.md) — set up the dev environment and run the
  checks.
